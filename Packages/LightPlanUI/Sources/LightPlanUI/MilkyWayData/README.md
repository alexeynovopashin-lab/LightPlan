# Данные Gaia для слоя «Млечный Путь» (шаг 29.8в.19)

Три файла — копия `Tools/milkyway_gaia/` без правки, кладёт их `make mwdata` (сверка побайтно):

| файл | что | формат |
|---|---|---|
| `stars_gaia.bin` | 482 106 звёзд Gaia DR3 с G ≤ 10, от ярких к слабым | `spec.json → stars` |
| `milkyway_glow_gaia.png` | свечение звёзд 10 < G ≤ 21, 1440 × 720, 16 бит RGB, линейная яркость | `spec.json → glow` |
| `spec.json` | раскладка файлов и таблица BP−RP → B−V для цвета звёзд | — |

Читает `MilkyWayGaia.swift` (`Screens/SunAR/`), один раз за запуск. Нет файла или он испорчен — слой рисует
прежнюю гладкую полосу шейдера `MilkyWaySky.metal` (запасной вариант 29.8в.17б), приложение работает.

- **До монетизации** (платная версия, подписка, покупки внутри, реклама, возможно донаты) **нужно письмо в ESA:

  файла убираются, слой сам уходит на запасной вариант.
- Юридически не проверялось.

## Панорама Млечного Пути (шаг 29.8в.20): `pano_mw2.jpg`

Слой Млечного Пути рисует эту картинку (MW2; Алексей оставил её, выбор MW / MW2 убран в 29.8в.24); файлы Gaia выше слой
больше не рисует.

- Источник: панорама eso0932a, https://www.eso.org/public/images/eso0932a/ — **ESO/S. Brunier**, материалы ESO под
  CC BY 4.0 (коммерция и изменения разрешены при видимом кредите и пометке об изменении).
- Кредит в приложении дословно: **«ESO/S. Brunier — панорама изменена (обрезка, градиенты)»** — строкой под «Млечный Путь»
  в списке «Слоёв» и в «О приложении» (`ar.mwPano`). Не сокращать, от слоя не отрывать.
- Изменения Алексея: обрезка, градиенты по краям; сверху наложена ещё одна картинка.
- В репозитории только уменьшенные копии 4096 × 1655, JPEG q92 (`Tools/mw_pano_prepare.py`); оригиналы 6000 × 2425
  (~25 МБ) не кладутся. Проекция: l = 0 в центре, l растёт влево, 0,06° на пиксель, по высоте 145,5°.
