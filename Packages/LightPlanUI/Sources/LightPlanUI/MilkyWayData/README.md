# Данные Gaia для слоя «Млечный Путь» (шаг 29.8в.19)

Три файла — копия `Tools/milkyway_gaia/` без правки, кладёт их `make mwdata` (сверка побайтно):

| файл | что | формат |
|---|---|---|
| `stars_gaia.bin` | 482 106 звёзд Gaia DR3 с G ≤ 10, от ярких к слабым | `spec.json → stars` |
| `milkyway_glow_gaia.png` | свечение звёзд 10 < G ≤ 21, 1440 × 720, 16 бит RGB, линейная яркость | `spec.json → glow` |
| `spec.json` | раскладка файлов и таблица BP−RP → B−V для цвета звёзд | — |

Читает `MilkyWayGaia.swift` (`Screens/SunAR/`), один раз за запуск. Нет файла или он испорчен — слой рисует
прежнюю гладкую полосу шейдера `MilkyWaySky.metal` (запасной вариант 29.8в.17б), приложение работает.
