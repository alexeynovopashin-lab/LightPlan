# 30г.3 — три кнопки режима, кадры настроек

Симулятор iPhone 17 Pro Max, 440 × 956 pt, `make shots --screens settings --modes simple,pro,astro`. `sheet.png`: сверху тёмная тема, снизу светлая; слева направо «Просто», «Про», «Астро».

| Что мерили | Число |
|---|---|
| Ряд кнопок, все шесть кадров | 392 × 45 pt |
| Каждая из трёх кнопок | 128,5 × 39 pt (было две по 193) |
| Подпись: «Просто», «Про» / «Астро» | 32,5 pt, две строки / 14,5 pt, одна строка (было 50,5) |
| Строки разделов от прежнего места | −18 pt в «Просто» и «Про», −36,3 pt в «Астро» |
| Шапка, строки разделов, панель вкладок против старой сборки | 0 px отличий |
| Выбранная кнопка: плашка / слово | тёмная #2a2724 / #efeae0, светлая #ddd6c8 / #17150f |
| Прочие кнопки: плашка / слово | тёмная #17150f / #8a8478, светлая #ffffff / #6b6559 |
| Звёзды на «Астро»: зазор до слова | 11,3 pt слева, 23,3 pt справа |
| «Про» против «Астро»: «Свет», «Карта» (свёрнута и раскрыта), глава «Вид» | 0 px, обе темы |
| Новая сборка против старой: те же экраны в «Просто» и «Астро» | 0 px, кроме главы «Вид» в светлой теме «Астро» |

Глава «Вид» в светлой «Астро» отличается на 2448 px: подпись впритык раздвигала там колонку до 392,5 pt, теперь 392 (сдвиг меньше 1 pt, правка `SetNote`). Слова подписей — черновик с рисунка `30g2_prostoe_sketch.png`.
