# MapCanvasSpike — холст карты

Песочница итерации 4. Отвечает на один вопрос: каким получается холст карты в
нативе и спорит ли он с разметкой прибора. Сравниваются два пути (§ 22
архитектуры), а не три из плана: растровый `MKTileOverlay` снят переходом веба
на вектор, свой рендер снят там же.

Проект отдельный: `LightPlan.xcodeproj` не трогает, пакеты не тянет.
Bundle id `Novopashin.LightPlan.map`. Единственная внешняя зависимость —
MapLibre Native 6.31.0 (SPM, `maplibre-gl-native-distribution`), и она есть
только здесь.

```
xcodebuild -project MapCanvasSpike.xcodeproj -scheme MapCanvasSpike \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build \
  > /tmp/cc-spike.log 2>&1; echo "exit=$?"
grep -nE 'error:|\*\* BUILD (SUCCEEDED|FAILED) \*\*' /tmp/cc-spike.log | head -20
```

## Что внутри

- `App/style_dark.json`, `App/style_light.json` — описание холста, снятое тем же
  `MAPSTYLE.build()` из `light_plan:Light_Plan/beta/mapstyle.js`. Не правятся
  руками: меняется веб — снимаются заново.
- `App/MapLibreCanvas.swift` — путь Б. Поворот и наклон выключены, как в вебе;
  атрибуция OSM/CARTO оставлена (условие бесплатного доступа к плиткам).
- `App/MapKitCanvas.swift` — путь А. Ширина кадра задана регионом в метрах,
  чтобы крупность совпадала с MapLibre числом: 1061 м поперёк кадра.
- `App/InstrumentOverlay.swift` — упрощённый прибор: лимб, две оси, путь солнца,
  светило. Латунь взята числами из веба. Полного прибора здесь нет.
- `App/RouteProbe.swift` — замер `MKDirections` на съёмочном дне Томска, машина
  и тропы. Кнопка «Маршруты Apple» на экране.
- `Shots/` — снимки для решения: два пути × две темы × город и природа.

## Итог, 20 сентября 2026

Разбор и числа — `light_plan:Light_Plan/DECISIONS.md`, «Холст карты в нативе:
MapKit против MapLibre». Коротко: MapLibre читает наш style JSON без переделки
и даёт тот же холст (земля `#15191C`, вода `#24343A` — совпадение точное);
MapKit своего цвета слоям не даёт, подписи улиц не выключаются, холст втрое
насыщеннее и синий против латуни. Цена MapLibre — 7 903 264 байта каркаса
(arm64) и однажды платные плитки. Выбор продуктовый, за Алексеем.

Маршруты Apple считаются и в России, и пешком: шесть отрезков дня за 2,43 с.
Путевых точек у `MKDirections` нет — день из четырёх точек это три запроса на
способ. Разбор там же, «Дополнение того же дня».

Проверено в симуляторе iPhone 17 Pro (iOS 26.5) и поставлено на телефон
Алексея; вердикта с телефона на 20 сентября ещё нет.
