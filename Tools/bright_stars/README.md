# Яркие звёзды для слоя звёзд AR

Звёзды неба ярче 2,5m, которых нет в фигурах созвездий «Астро»
(`ConstellationCatalog`, 163 звезды из `beta/sky.js`). Слою звёзд AR нужны и
они: Канопус, Альфа Центавра, Южный Крест, Фомальгаут в фигуры не входят.

```
make brightstars                      сборка JSON → Swift → проверка, без сети
node Tools/bright_stars/fetch.js      обновить снимки источников (нужна сеть)
```

## Файлы

| Файл | Что это |
|---|---|
| `bright_stars.json` | **источник правды** для Swift: 90 звёзд, блоки `inFigures` (59, уже есть в фигурах — запись сверки) и `added` (31, новые); `excluded` — исключённые с причиной |
| `build.js` | снимки `sources/` + правила → `bright_stars.json`; руками JSON не правят — правило меняется здесь |
| `gen_swift.js` | `bright_stars.json` → `Packages/LightPlanCore/Sources/LightPlanCore/Sky/BrightStars.generated.swift` (только `added`); `--check` — файл совпадает с JSON |
| `check.js` | проверка числами, строки «да / НЕТ», любое «НЕТ» — код 1 |
| `fetch.js` | скачивает снимки в `sources/` через `curl` |
| `sources/v50.tsv` | Yale Bright Star Catalogue, звёзды V < 2,6, исходные столбцы каталога |
| `sources/iau_csn.txt` | шапка списка имён МАС (с условиями использования) и строки наших звёзд |
| `sources/wikidata_ru.json` | русские метки и заголовки статей ру-Википедии для каждой звезды |
| `sources/simbad.json` | координаты SIMBAD — только для сверки, в каталог не идут |

Каталог созвездий для сверки читается из нативного
`ConstellationCatalog.generated.swift`, папка веба не нужна. Он совпадает с
`beta/sky.js` ветки `main` веба: `Tools/sky2swift.js` на `6f07823` пишет
побайтово тот же файл (проверено 19.10.2026).

## Источники, версии, условия

1. **Координаты, величины, спектры — Yale Bright Star Catalogue, 5th Revised
   Ed.** (Hoffleit D., Warren Jr W. H., Astronomical Data Center, NSSDC/ADC,
   1991; предварительная версия), каталог VizieR **V/50**
   (<https://cdsarc.cds.unistra.fr/viz-bin/cat/V/50>, в CDS с 1997-12-09).
   Снимок 19.10.2026, сервер VizieR 7.6.1. Координаты — FK5, равноденствие и
   эпоха J2000, точность каталога 0,1 с по RA и 1″ по Dec.
   *Условия.* В ReadMe каталога V/50 оговорок об авторском праве или лицензии
   нет (поиск «copyright / licen / rights / restrict» — ноль совпадений).
   Правила VizieR (<https://cds.unistra.fr/vizier-org/licences_vizier.html>):
   данные свободны для использования; при публикации — ссылка на авторов
   каталога и на VizieR (DOI 10.26093/cds/vizier); для коммерческого
   использования — смотреть ReadMe каталога: у V/50 ограничений там нет.
   Ссылку на источник стоит дать в «О приложении»: «Данные звёзд: Yale Bright
   Star Catalogue, 5th ed. (Hoffleit & Warren 1991), CDS VizieR».
   Юридически не проверялось.
2. **Английские имена — МАС, рабочая группа WGSN.** Список IAU-CSN от
   2022-04-04 (<https://www.pas.rochester.edu/~emamajek/WGSN/IAU-CSN.txt>,
   ведёт секретарь WGSN). Условия в шапке файла: продукты МАС — «Creative
   Commons Attribution», свободно при указании источника. Два имени приняты
   позже и в файле их нет — взяты из новостей WGSN: Tiansi (γ Cas, 2025,
   <https://exopla.net/news-in-2025/>), Uridim (α Lup, 2024,
   <https://exopla.net/new-star-names-2024/>). У звёзд без имени МАС — латинское
   обозначение Байера («Gamma Centauri»).
3. **Русские имена — русская Википедия через Wikidata** (данные Wikidata —
   CC0, без ограничений). Большая российская энциклопедия (`bigenc.ru`) из
   облака закрыта (HTTP 401) — с ней не сверено.
4. **Сверка координат — SIMBAD** (CDS, ICRS, эпоха J2000; Gaia/Hipparcos —
   независимо от BSC). Использован только для проверки; при публикации CDS
   просит строку «This research has made use of the SIMBAD database, CDS,
   Strasbourg Astronomical Observatory, France».

## Правила сборки

- **Граница:** V ≤ 2,5 включительно — в V/50 таких 93.
- **Исключена T Северной Короны (HR 5958):** повторная новая, V/50 даёт ей
  2,00 — блеск вспышки, в покое она около 10m (SIMBAD V = 10,25) и глазу не
  видна.
- **Пары ближе 0,05° — одна точка:** α¹ + α² Центавра (−0,01 и 1,33 → −0,29) и
  α¹ + α² Южного Креста (1,33 и 1,73 → 0,76). Глаз их не делит, две точки друг
  на друге были бы дублем. Величина — суммарный блеск, место и HR — яркой
  компоненты, спектр — через «+», состав пары — в поле `components`.
  Сливаются только звёзды ярче 2,5: слабые компаньоны (Кастор B 2,88,
  γ¹ Парусов 4,27) не прибавлены.
- **«Уже есть»** — звезда ближе 0,05° к одной из 163 звёзд фигур. Таких 59;
  Альферац и Эльнат стоят в двух фигурах сразу. В Swift уходит только блок
  `added` (31 звезда), чтобы одна звезда не рисовалась дважды.
- **Русское имя — у 30 самых ярких** (ранг после слияния пар). Имя принято,
  только если и заголовок статьи ру-Википедии, и русская метка Wikidata — у
  самой звезды или у её системы (свойство «часть от»: у «Сириус A» статьи нет,
  у системы «Сириус» есть) — равны ему. Ниже 30-го ранга русских имён нет.
  - **β Тельца (Elnath) — без русского имени:** метка Wikidata «Нат», статья
    «Бета Тельца», в ходу и «Эльнат» — источники расходятся, оставлено
    латинское.
  - **β Киля:** имя МАС — Miaplacidus, русская Википедия называет её
    обозначением «Бета Киля» — так и записано.
  - **β Южного Креста:** МАС — Mimosa, по-русски — «Бекрукс».
  - **α Центавра:** английское имя — МАС для яркой компоненты (Rigil
    Kentaurus), русское — имя системы «Альфа Центавра».
- **Собственное движение не прибавлено:** координаты на 2000 год, как и у
  каталога созвездий. Быстрее всех движется α Центавра — 3,7″ в год, к 2026
  году ≈ 0,03°.

## Что показывает проверка (`check.js`, 19.10.2026)

- поля: 90 звёзд, RA 0,140…23,079 ч, Dec −69,72…89,26°, V −1,46…2,50;
- дублей нет: ближайшая пара — ε и ζ Ориона, 1,356°;
- в фигурах: 59 звёзд, дальше всех от точки фигуры — Менкалинан (β Aur),
  0,0305°: в `beta/sky.js` RA 5,995 ч против 5,99214 ч по V/50 и SIMBAD — в
  пределах допуска, но это самая неточная точка фигур среди ярких звёзд;
- добавленные: ни одной звезды фигур ближе 0,05°, ближайшая — Рас Альхаге,
  5,26° от звезды Геркулеса;
- SIMBAD: сверены все 90 звёзд, медиана расхождения 0,47″, максимум 6,44″
  (α Центавра — быстрая двойная) при допуске 0,02° = 72″;
- русские имена: 29 из 30 подтверждены, без имени — β Тельца;
- повторная сборка из снимков даёт тот же JSON и тот же Swift побайтово.
